## Key Patterns Observed (General SaaS Best Practices)

### Trust & Security
- **Trillions processed** — massive scale as trust signal
- **Fortune 100 / Forbes Cloud 100** — elite customer segments
- **Trust Center** in Resources nav
- **Security page** in Company nav
- **Professional services** for enterprise implementation
- **Certified partner ecosystem** — implementation confidence

### Interactive Demo
- **Live code samples in 7 languages** — immediate technical evaluation
- **"No code" Dashboard option** — non-technical entry
- **Pre-integrated platforms** — low-friction evaluation
- **MCP Server / AI Tools** — emerging developer persona
- **Pay-as-you-go, no setup fees** — low barrier to try

### Buyer Journey
- **Solutions by Business Model** (SaaS, Marketplaces, Platforms, etc.) — 7 distinct models
- **By Stage** (Startups, Enterprises) — lifecycle segmentation
- **By Use Case** — problem-based entry
- **Developer-first** with code samples
- **Non-technical path** (Dashboard, pre-integrated platforms)

### Social Proof
- **"Trillions of dollars annually"** — quantified scale
- **"Fortune 100", "Forbes Cloud 100"** — prestigious segments
- **"125+ payment methods, 135+ currencies"** — global reach metrics
- **Customer Stories** in Resources
- **Professional services / certified partners** — ecosystem maturity

### Technical Credibility
- **Code samples in 7 languages** above the fold — strongest technical credibility pattern
- **Comprehensive SDKs for all major languages**
- **MCP Server / AI Tools** — AI agent infrastructure
- **API Reference, SDKs, Apps** as first-class Developer nav
- **Status page, Changelog** — reliability/velocity signals
- **AI-powered support, debugging tools** — developer experience investment

### SEO/Content
- **Blog, Guides, Events, Customer Stories, Help Center, Support, Trust Center**
- **Guides** as educational content
- **Solutions by Business Model/Stage/Use Case** — massive SEO surface area
- **Documentation** as primary developer entry point

### Pricing
- **Pricing in main nav** — transparent
- **"Simple, pay-as-you-go pricing"** — clear model
- **"No setup fees"** — barrier removal
- **Enterprise professional services** separate
