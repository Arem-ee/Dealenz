### 3. Agent Specifications (Detailed)
Each agent has specific capabilities listed:
- **Extraction:** Source-linked answers, explainable
- **Drafting:** Negotiation-ready drafts from enterprise data/playbooks
- **Review:** Full context analysis, spots clause-level issues
- **Redlining:** Surgical revisions, policy-backed explainable changes
- **Playbook:** Transforms policies into smart templates
- **Data Population:** Pulls structured data, populates systems
- **Obligation Tracking:** Tracks every commitment, surfaces at-risk obligations
- **Invoice Reconciliation:** Reconciles invoices against contract terms, detects mismatches

### 5. Manage Contracts Page (/platform/manage/)
